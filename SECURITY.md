# Security Policy

## Supported Versions

Security fixes are currently provided for the latest released version on the
`main` branch.

## Reporting A Vulnerability

Please do not open a public issue for security-sensitive reports.

Instead, report vulnerabilities through one of these channels:

- GitHub Security Advisories for this repository
- a private contact method controlled by the maintainer

Please include:

- affected version
- operating system
- Python version
- `frida` version
- reproduction details
- impact summary

The maintainer will review the report and respond as quickly as possible.
