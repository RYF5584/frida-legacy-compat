# frida-legacy-compat 1.1.0

`frida-legacy-compat` 1.1.0 is a usability update focused on explicit activation and softer compatibility handling.

## Highlights

- importing `frida_legacy_compat` no longer auto-patches `frida.core.Session.create_script()`
- the compatibility layer is now enabled explicitly through `frida_legacy_compat.patch_frida()`
- package installation no longer restricts the installed `frida` version
- unsupported or unvalidated Frida versions now emit localized warnings instead of raising
- both import-time checks and explicit patch activation keep unsupported environments non-fatal

## Compatibility

- `frida < 17`: installable; import and `patch_frida()` warn and remain no-op
- `17.0 <= frida < 17.2`: installable; import and `patch_frida()` warn that `frida>=17.2,<18` is recommended
- `17.2 <= frida < 18`: supported
- `frida >= 18`: installable; import and `patch_frida()` warn that the version is outside the validated range
