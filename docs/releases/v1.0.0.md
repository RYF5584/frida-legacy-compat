# frida-legacy-compat 1.0.0

`frida-legacy-compat` 1.0.0 is the first public release of the project.

## Highlights

- restores a Frida 16-style Python `session.create_script()` workflow on top of Frida 17+
- automatically patches `frida.core.Session.create_script()`
- compiles legacy plain JavaScript agents on demand and injects `Java`, `ObjC`, and `Swift` globals
- keeps `frida < 17` projects safe with a silent no-op import path
- warns immediately when `17.0 <= frida < 17.2` is detected
- fixes legacy script loading order so bridge globals are ready before user code runs

## Compatibility

- `frida < 17`: installable and safe to keep imported; defaults to a silent no-op
- `17.0 <= frida < 17.2`: installable; both import and patch activation warn that `frida>=17.2,<18` is required
- `17.2 <= frida < 18`: supported
- `frida >= 18`: currently unvalidated
