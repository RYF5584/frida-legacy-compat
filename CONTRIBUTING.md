# Contributing

Thank you for your interest in contributing to `frida-legacy-compat`.

## Development Setup

```bash
uv sync
uv build
```

## Project Scope

Contributions are especially welcome for:

- Frida 17.x compatibility improvements
- Bridge version matrix updates
- Cross-platform testing
- Documentation and examples
- Packaging and release workflow improvements

## Pull Requests

Please keep pull requests focused and include:

- a short problem statement
- the reasoning behind the change
- build or manual validation notes when relevant
- documentation updates if user-facing behavior changes

## Reporting Issues

When reporting compatibility issues, please include:

- operating system
- Python version
- `frida` version
- target platform, such as Android or iOS
- exact error output
- whether custom bridge versions were used
